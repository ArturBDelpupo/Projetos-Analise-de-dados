# Projetos e Exercícios de Análise de Dados com Python

Repositório dedicado ao estudo prático de Análise de Dados e manipulação de diferentes bases de dados utilizando a linguagem Python.

---

## Sobre o Repositório

Os exercícios e projetos reunidos aqui foram desenvolvidos com foco na exploração, tratamento, limpeza e visualização de dados em diversos cenários e áreas de negócio (como indústria de jogos, mercado financeiro, negócios, entre outros).

As atividades práticas foram baseadas no curso **Python para Análise de Dados** do canal **Data Viking**:
- Canal no YouTube: [Data Viking](https://www.youtube.com/@DataVikingx)

---

## Tecnologias e Bibliotecas Utilizadas

- **[Python](https://www.python.org/)** (Linguagem base)
- **[Pandas](https://pandas.pydata.org/)** (Manipulação e estruturação de dados)
- **[NumPy](https://numpy.org/)** (Operações numéricas e matriciais)
- **[Matplotlib](https://matplotlib.org/)** / **[Seaborn](https://seaborn.pydata.org/)** (Visualização gráfica e geração de insights)

## Como Executar Localmente

1. **Clone o repositório:**
   ```bash
   git clone git@github.com:ArturBDelpupo/Projetos-Analise-de-dados.git
   cd Projetos-Analise-de-dados
   ```

2. **Crie e ative um ambiente virtual (recomendado):**
   ```bash
   python -m venv .venv
   # Windows (PowerShell):
   .venv\Scripts\Activate.ps1
   ```

3. **Instale as dependências necessárias:**
   ```bash
   pip install pandas numpy matplotlib seaborn
   ```

4. **Execute qualquer um dos scripts:**
   ```bash
   python EX4_Games.py
   ```
